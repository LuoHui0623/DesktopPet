# 状态层与行为解析

> 职责：定义状态注册表、行为解析器、状态表、缺失状态的回退链与状态扩展方式。
> 依赖：`module/avatar/constants.py`、前端 `avatar-state.ts`、`service/avatar.service.ts`；行为事件来自聊天与连接层。
> 不回答：事件产生时机、动画解码与播放、掩码与窗口穿透。
> 状态：已实现。

## 1. 状态层的位置

```text
聊天状态事件 ┐
连接状态事件 ├─► 解析器注册表 ─► 状态键
后续行为事件 ┘
                              └─► 状态表（状态键 → AnimationResource）
                                    └─► 播放 / 命中与穿透判定
```

- 行为解析只产出状态键，不选帧、不读掩码、不决定持续时间。
- 状态表只产出动画资源，不直接读帧文件或 GIF。
- 播放与命中只消费状态表，不感知状态数量或资源格式。

## 2. 状态词表与注册表

- 后端 `module/avatar/constants.py` 的 `StateRegistry` 是状态词表的唯一来源。
- 内置状态按固定顺序初始化：

```text
idle → thinking → speaking → executing → sleeping → disconnected
```

- 注册表可登记新状态；登记后随 `GET /api/avatars` 的 `preset_states` 下发。
- 前端不自行发明状态名，按 `preset_states` 顺序建表。
- 包使用未注册状态名时，加载告警后忽略；该状态不进入状态表。
- 只登记不挂载资源时，该状态查询会走回退链。

## 3. 行为解析

解析器是注册函数，输入行为上下文，输出状态键或 `null`：

```text
解析器 1 → 状态键 / null
解析器 2 → 状态键 / null
...
取首个非空且已注册的结果
```

- 解析器按注册优先级取首个非空结果。
- 全部为空或结果未注册时，保持上一次解析出的状态；从未解析成功时返回 `null`。
- 内置解析器覆盖连接状态与聊天状态：连接断开优先映射 `disconnected`，否则取当前聊天状态；没有聊天状态时映射 `disconnected`。
- 新增行为只注册解析器；必要时同时登记新状态，不需要改播放、命中与穿透判定。

## 4. 状态表与资源挂载

- 一个预设状态最多对应一个 `AnimationResource`。
- 资源解析按 manifest 状态名把动画挂载到状态；同一状态的多帧内容整体作为一个动画注册。
- 状态表按形象包隔离；切换包时整表替换，旧动画、位图与掩码一并释放。
- 缺失状态不在注册期复制动画；查询时按回退链解析，避免同一动画重复持有。
- 行为解析器只在 `preset_states` 变化时重建；换包时解析器与状态表一起更新。

## 5. 回退链

查询状态键时按以下顺序取动画：

```text
请求状态动画 → manifest.fallback 动画 → 静默主形象 → null（内联占位）
```

- 静默主形象不属于任何状态，只能作为最后一级兜底。
- 每一级解码或挂载失败只降级，不抛未捕获异常。
- 占位状态下交互退化为整窗可交互，不因缺资源阻塞窗口使用。
- `disconnected` 由连接状态触发，不依赖后端发送状态事件。

## 6. 状态扩展

新增一个状态分两步：

1. 后端状态注册表登记状态键。
2. 包在 manifest 中挂载该状态的动画。

完成后 `preset_states` 自动包含新状态，前端状态表自动建键；播放、命中与穿透判定不需要改状态清单。

新增一个行为只需注册解析器；如果行为映射到已有状态，不新增状态，也不改资源。

## 7. 失败与边界

| 情况 | 行为 |
|---|---|
| 缺失某个已注册状态 | 使用 `manifest.fallback` 的动画 |
| fallback 动画解码或挂载失败 | 使用静默主形象 |
| 静默主形象也不可用 | 内联占位 |
| 未注册状态名 | 告警后忽略，不进入状态层 |
| 解析不到状态 | 保持当前状态，不切换动画 |
| 切换形象包 | 整表替换，不残留旧包动画 |

## 8. 非目标

- 不做通用行为规则引擎；解析器只做行为到状态的映射。
- 不编排聊天状态机、不设置状态优先级、不决定状态持续时间。
- 不让包自定义状态名；状态扩展必须经后端注册表。
- 不在状态层生成或解析动画帧、掩码与绘制矩形。

## 9. 已定口径

- 行为解析 → 状态 → 动画：解析器只产出状态键，状态层只产出动画，动画资源只负责帧、时长与掩码。
- 状态注册表可扩展，但包不能自造状态；新增状态必须后端登记并有资源挂载。
- 回退链固定为状态动画 → fallback 动画 → 静默主形象 → 内联占位。
- 解析不到状态时保持当前状态，不切回默认动画。
- 状态与行为来源见 [CHAT.md](../CHAT.md)、[PROACTIVE.md](../PROACTIVE.md)；资源与播放见 [PACK.md](PACK.md)、[ANIMATION.md](ANIMATION.md)。
