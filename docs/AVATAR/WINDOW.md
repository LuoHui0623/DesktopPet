# 悬浮窗命中与穿透

> 职责：定义悬浮窗如何绘制当前动画、哪些区域可交互、如何用光标轮询切换穿透开关，以及按压与拖动期间的锁定规则。
> 依赖：`PetView.tsx`、`PetWindow.tsx`、`avatar-hit.ts`、`pass-through.ts`、`pet-hit-state.ts`；Tauri 窗口 API 与窗口 capability。
> 不回答：包与 manifest 校验、状态选择、动画解码、聊天与互动业务。
> 状态：已实现（Windows 优先）。

## 1. 窗口与渲染

- 悬浮窗是 320×360 逻辑像素的透明、无边框、置顶窗口；界面根容器按 WebView 实际 CSS 视口铺满，避免视口尺寸小于固定布局时被裁切；窗口内除形象与信息面板外的区域保持透明。
- 形象用固定 120×120 的 canvas 槽位绘制；逻辑画布按 `contain` 放入槽位，水平居中、底边贴底。
- 当前帧来自状态层选出的 `AnimationResource`，由播放器按累计时间轴换帧；画面与掩码使用同一帧。
- 形象、状态标签与气泡之外的区域不绘制背景，也不承担拖动。
- 加载完成前显示静态主形象，整窗可交互；动态资源就绪后按帧掩码判定。

## 2. 可交互范围

```text
可交互 = 当前帧不透明像素 ∪ 状态标签矩形 ∪ 感知气泡矩形 ∪ 主动气泡矩形
```

- 形象按当前帧掩码判定；掩码为 `null`（整帧透明、加载中或损坏）时按整块命中。
- 状态标签按实际 DOM 矩形命中，不加额外 padding。
- 气泡按实际 DOM 矩形命中，含按钮与阴影 padding（10px）；气泡出现即可点，消失后矩形移除。
- 其余区域整窗穿透，左键、右键与滚轮都落到桌面。
- 没有帧信息或窗口开关不可用时按整窗可交互处理，保证加载期与降级时不丢点击。

## 3. 坐标链

```text
全局光标物理坐标
  → 减窗口物理位置
  → 分别乘 WebView CSS 视口宽/高与窗口物理宽/高之比
  → 窗口内 CSS 坐标
  → 与 canvas 的 getBoundingClientRect 相加
  → 得到绘制矩形内的局部坐标
  → 映射回资源像素
  → 查 1bpp 掩码
```

- 换算比例基于实时窗口物理尺寸和 WebView CSS 视口尺寸，不假设系统 DPI 与 WebView 缩放相同；125% / 150% 与双屏切换都按同一公式换算。
- `getBoundingClientRect` 在调用时读取，窗口移动后不需要额外失效步骤。
- 资源像素坐标按绘制矩形比例换算，并夹在资源尺寸内；落在绘制矩形外直接视为未命中。
- 绘制、命中与穿透共用同一个绘制矩形，不使用 120×120 元素框代替。

## 4. 命中状态机

- `pointerdown` 命中后锁定，锁定即进入拖动候选；未命中不锁定、不启动拖动。
- 锁定期间多次 `pointermove`、换帧、指针移出与穿透开关变化都不重新判定命中。
- `pointerup` / `pointercancel` 释放锁定；下一次按压重新判定。
- `pointerenter` 在未锁定时只判定一次；`pointerleave` 在未锁定时清除悬停，锁定期间忽略。
- 悬停与点击只对形象像素、标签与气泡生效；透明区域的指针事件由穿透开关交给桌面。
- 拖动入口只有形象与状态标签；`main` 与空白容器不再带整窗拖动区。

## 5. 穿透轮询与开关

- 前端每 16ms 读取一次全局光标、窗口位置与缩放，换算到窗口内坐标。
- 只在“可交互 / 穿透”结果变化时调用一次 `set_ignore_cursor_events`；结果稳定时不重复调用。
- 异步写入串行化：连续跨越边界时，后一次结果不会被旧调用覆盖。
- 按压命中后冻结开关；拖动、换帧与指针移出都不切换，松开或取消后立即按当前位置恢复。
- 切到穿透时停止悬停计时；切回可交互且指针仍在形象像素上时恢复悬停，避免反应残留。
- 读取光标失败或判定异常时按整窗可交互处理；开关调用失败时永久退化为整窗可交互，不抛未捕获异常。
- 窗口停止或销毁时清除定时器；若当前处于穿透，恢复接收鼠标事件。

## 6. 事件接线

| 事件 | 行为 |
|---|---|
| 左键 `pointerdown` | 命中则锁定并冻结穿透；未命中不处理 |
| `pointermove` / `pointerenter` / `pointerleave` | 未锁定时更新悬停；锁定期间忽略 |
| `pointerup` / `pointercancel` | 结束拖动、释放锁定、解冻穿透 |
| 点击 | 命中形象、标签或气泡时上报互动并打开对话 |
| 右键 | 结束拖动、释放锁定、解冻，弹出应用菜单；形象外右键由穿透交给桌面 |
| 窗口移动 | 上报拖动行为，不影响命中锁定 |

- 互动上报、节流与反应动画由互动服务负责；本层只决定事件是否成立。
- 右键菜单结构与动作由后端读模型与原生菜单负责，本层只负责触发。

## 7. 矩形缓存与刷新

- 标签、感知气泡与主动气泡的矩形在布局变化时刷新并缓存；轮询只读缓存，不为每次采样重新测量 DOM。
- 使用 `ResizeObserver` 观察形象槽位、标签与气泡；窗口 resize 时再次刷新。
- 气泡出现或消失后，下一次轮询使用新的矩形集合。
- 窗口移动、跨屏或缩放后，坐标换算与绘制矩形会在下一次轮询和命中时重新读取。

## 8. 失败与降级

| 情况 | 行为 |
|---|---|
| 形象加载中、无掩码或掩码损坏 | 整窗可交互，不穿透 |
| 静态主形象不可用 | 显示占位 SVG，整窗可交互 |
| 光标读取失败 | 按整窗可交互处理 |
| 开关调用失败 | 退化为整窗可交互，不再尝试切换 |
| 轮询异常 | 记录错误，不阻断窗口使用 |
| 按压后指针移出形象 | 锁定持续到释放或取消 |

## 9. 约束与非目标

- 穿透只靠光标轮询与窗口忽略开关，不新增系统区域、不向 Rust 传递掩码。
- 以 Windows 为准；其它平台的穿透实现不在本轮契约内。
- 不追求将透明区域从系统窗口形状中裁掉；窗口保持矩形透明。
- 不定义动画解码、状态回落与包校验；这些见 [ANIMATION.md](ANIMATION.md)、[STATE.md](STATE.md)、[PACK.md](PACK.md)。

## 10. 已定口径

- 可交互范围 = 当前帧掩码 ∪ 状态标签 ∪ 气泡（含阴影 padding）；其余区域穿透到桌面。
- 命中在按压时判定并锁定，拖动持续到释放或取消；锁定期间不重新判定。
- 开关只在结果变化时调用，按压与拖动期间冻结；失败退化为整窗可交互。
- 绘制、命中与穿透共用绘制矩形；锚点取资源矩形中心，水平居中、底边贴底。
- 拖动入口只有形象与状态标签，空白容器不承担拖动。
