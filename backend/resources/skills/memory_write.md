# 记忆写入

> 把主人值得长期记住的信息写进结构化记忆文档 `structured.md`。主人明确提出「记住」「记一下」，说出会持续成立的偏好、习惯、约定或重要安排，或纠正了以前记下的同类信息时，使用本技能。一次性、临时的信息不写入。

## 执行流程

1. **判断信息类型**：确认主人表达的是长期有效的信息（偏好、习惯、约定、安排、纠正），而非一次性内容。
2. **先看清现状**：调用 `index`（资源类型 `memory`）查看结构化记忆的行数与已有标题，再用 `read`（资源类型 `memory`，`name` 取 `structured`）读出全文和行号。文档初始是空的，结构完全由你自己设计。
3. **设计结构**：第一次写入时自己决定怎么组织，例如先写一行标题（`## 工作`），再写条目（`工作地点：杭州`）。之后沿用已有结构，有新材料再补标题，不必每次推翻重来。
4. **新增或更新**：
   - 新信息：调用 `memory_append` 追加内容，可以多行。
   - 纠正旧信息：确认要改的行号后调用 `memory_replace`。`lines` 是行号位置，可同时写多段（如 `[[5, 6], [9, 12]]`），单行写 `[7]`；`pattern` 是 Python 正则，只在指定行内匹配；`content` 替换匹配到的文字，同一行其他内容保持不变。只改一行里的某个值时不要整段重写。
5. **告知结果**：完成后用一句话告知主人记住了什么。

## 约束

- 不要记录主人没有表达的内容。
- 文档是自由文本文件，没有字段和 id：定位与修改全靠行号，改完后以工具返回的行号为准。
- 正则只在确认过的行号内生效；没有匹配到内容时工具会报错，此时先 `read` 复核原文再重试，不要盲改。
- 写入前检查是否开启临时模式，临时模式下不写入。
- 敏感信息（密码、身份证号等）拒绝写入。
