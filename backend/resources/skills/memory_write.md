# 记忆写入

> 把主人值得长期记住的信息写进结构化记忆文档 `structured.md`。主人明确提出「记住」「记一下」，说出会持续成立的偏好、习惯、约定或重要安排，或纠正了以前记下的同类信息时，使用本技能。一次性、临时的信息不写入。

## 执行流程

1. **判断信息类型**：确认主人表达的是长期有效的信息（偏好、习惯、约定、安排、纠正），而非一次性内容。
2. **先看清现状**：调用 `index`（资源类型 `memory`）查看结构化记忆的规模与标题，再用 `read`（资源类型 `memory`，`name` 取 `structured`）读出全文和行号。
3. **新增或更新**：
   - 新信息：调用 `memory_append` 追加。可以多行，主题开头先写一行标题（如 `## 工作`），再写条目（如 `工作地点：杭州`）。
   - 纠正旧信息：确认要改的行号后调用 `memory_replace`，用新内容覆盖这些行；旧内容不保留。
4. **告知结果**：完成后用一句话告知主人记住了什么。

## 约束

- 不要记录主人没有表达的内容。
- 文档是自由文本大纲，没有字段和 id，定位与修改全靠行号。
- 写入前检查是否开启临时模式，临时模式下不写入。
- 敏感信息（密码、身份证号等）拒绝写入。
