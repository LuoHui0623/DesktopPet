# 记忆写入

> 把主人值得长期记住的信息写进结构化记忆文档。主人明确提出「记住」「记一下」，说出会持续成立的偏好、习惯、约定或重要安排，或纠正了以前记下的同类信息时，使用本技能。一次性、临时的信息不写入。

## 执行流程

1. **判断信息类型**：确认主人表达的是长期有效的信息（偏好、习惯、约定、安排、纠正），而非一次性内容。
2. **先看清现状**：调用 `index`（`resource` 取 `structured`）查看行数与已有标题，再用 `read`（`resource` 取 `structured`）读出全文和行号。文档初始是空的，结构完全由你自己设计。
3. **设计结构**：第一次写入时自己决定怎么组织，例如先写一行标题（`## 工作`），再写条目（`工作地点：杭州`）。之后沿用已有结构，有新材料再补标题，不必每次推翻重来。
4. **新增或更新**（`resource` 固定取 `structured`，所有写入走 `edit`）：
   - 新信息：`{"action": "append", "content": "..."}` 追加到末尾，可以多行；需要插到中间时用 `{"action": "insert", "line": 3, "content": "..."}`。
   - 纠正旧信息：`{"action": "replace_lines", "line_ranges": [[5, 5]], "content": "..."}` 整段替换指定行；`expect` 填目标行原文，与实际不符时不会写入。
   - 局部改字：`{"action": "replace_regex", "line_ranges": [[3, 8]], "pattern": "旧", "content": "新"}` 只在给定行范围内做正则替换；行范围必填。
   - 删条目：`{"action": "delete", "line_ranges": [[5, 5]]}`；结构化记忆不能删除文件本体。
   - 结构化记忆会立即写入，不经过草稿审批；写入后以工具返回的行号为准。
5. **告知结果**：完成后用一句话告知主人记住了什么。

## 约束

- 不要记录主人没有表达的内容。
- 文档是自由文本文件，没有字段和 id：定位与修改全靠行号，改完后以工具返回的行号为准。
- 敏感信息（密码、身份证号等）拒绝写入。

## 输出

`output` 写一句给主人看的结论，例如「记住了你更喜欢美式咖啡」。
