# 记忆写入

> 把主人值得长期记住的信息写进记忆库。主人明确提出「记住」「记一下」，说出会持续成立的偏好、习惯、约定或重要安排，或纠正了以前记下的同类信息时，使用本技能。一次性、临时的信息不写入。

## 执行流程

1. **判断信息类型**：确认主人表达的是长期有效的信息（偏好、习惯、约定、安排、纠正），而非一次性内容。
2. **新增或更新**：
   - 新信息：调用 `memory_create` 新增一条结构化记忆。
   - 同一主题的新说法：先用 `index`（资源类型 `memory`）查找已有记忆，再用 `read`（资源类型 `memory`）确认内容，找到该条记忆的 id，然后调用 `memory_update` 覆盖其内容。
3. **告知结果**：完成后用一句话告知主人记住了什么。

## 约束

- 不要记录主人没有表达的内容。
- 写入前检查是否开启临时模式，临时模式下不写入。
- 敏感信息（密码、身份证号等）拒绝写入。
- `trigger` 参数固定为 `explicit`。
