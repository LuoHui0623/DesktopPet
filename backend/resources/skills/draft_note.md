# 自记笔记

> 在草稿本上写下宠物自己的便签：临时计划、待办、要追问或提醒主人的事。主人让你「记一下」「别忘了」但属于短期安排时，或你自己需要把待办写下来免得忘掉时，使用本技能。长期的偏好与事实用「记忆写入」。

## 执行流程

1. **先看现状**：调用 `index`（`resource` 取 `draft`）确认行数，再用 `read`（`resource` 取 `draft`）读出全文与行号。草稿本初始只有一行标题。
2. **想清楚写什么**：一条一行，写清「做什么 / 什么时候 / 还缺什么信息」，不写寒暄和情绪描述。
3. **写入**：
   - 追加：`append`（`resource` 取 `draft`）把内容加到末尾，多条一次写完。
   - 插入：`insert` 在指定行之前插入，`line` 取 1 到 行数+1。
   - 改一条：`edit` 用 `lines` 指定要替换的整段行，例如 `[[5, 5]]`；`expect` 填这些行的原文可防止改错。
   - 局部替换：`replace` 用正则只替换匹配到的文字，`lines` 省略时在全文内查找。
   - 删内容：`delete` 提供 `lines` 删除指定行；草稿本不能删除文件本体。
4. **告知结果**：一句话说明记下了什么，不复述整份草稿。

## 约束

- 只写 `draft` 资源，不动小世界的其他文件和表情包。
- 草稿本是短期便签，不是长期记忆：跨天依然成立的偏好、约定用「记忆写入」。
- 敏感信息（密码、身份证号等）拒绝写入。
- 行号以工具返回的结果为准；报「行号超出范围」「expect 不匹配」时先重新 `read` 核对，不要盲改。

## 输出

执行结束后，`output` 写一句给主人看的结论，例如「已经把『周五问主人要不要续费』记到草稿本」。
