# 自记笔记

> 在草稿本 `草稿本.md` 上写下宠物自己的便签：临时计划、待办、要追问或提醒主人的事。主人让你「记一下」「别忘了」但属于短期安排时，或你自己需要把待办写下来免得忘掉时，使用本技能。长期的偏好与事实用「记忆写入」。

## 执行流程

1. **先看现状**：调用 `file_read`（`path` 填 `草稿本.md`）读出全文，确认已有内容与段落序号。草稿本初始只有一行标题。
2. **想清楚写什么**：一条一行，写清「做什么 / 什么时候 / 还缺什么信息」，不写寒暄和情绪描述。
3. **写入**：
   - 追加：`file_write` 是整篇覆盖，先把旧内容读出来，写入「旧内容 + 一个空行 + 新条目」。
   - 改一条：`file_edit` 按段落序号替换，段落以空行分隔、序号从 1 开始；只改一条时不要整篇重写。
   - 清空：`file_clear` 只清内容、保留文件，只在主人明确要求清空时使用。
4. **告知结果**：一句话说明记下了什么，不复述整份草稿。

## 约束

- 只写 `草稿本.md`，不动 `表情包` 目录和其他文件。
- 草稿本是短期便签，不是长期记忆：跨天依然成立的偏好、约定用「记忆写入」。
- 敏感信息（密码、身份证号等）拒绝写入。
- 段落序号以工具返回的结果为准；`file_edit` 报「段落不存在」时先重新 `file_read` 核对，不要盲改。

## 输出

执行结束后，`output` 写一句给主人看的结论，例如「已经把『周五问主人要不要续费』记到草稿本」。
