# 记忆检索

> 主人询问与过去记忆相关的问题时，使用本技能。通过资源索引探索结构化记忆与永久记忆，找到相关片段并返回给主 agent。

## 执行流程

1. **定位资源**：记忆域只有 `structured` 与 `permanent` 两个只读资源；`index`（`target` 取 `MEMORY`）只列名字，正文一律用 `read` 读取。
2. **按需读取**：
   - 结构化记忆：`read`（`resource` 取 `structured`），按分区列出条目（Markdown 树，不展示条目 id），`[已弃用]` 是暂停使用的条目。
   - 永久记忆：`read`（`resource` 取 `permanent`），用 `date` 读取某一天，或用 `from`/`to`（ISO 8601）读取一段范围；只返回当前人设的记录。
3. **先搜再读**：内容多时先用 `grep`（`resource` 取 `structured` 或 `permanent`，永久记忆同样用 `date`/`from`/`to` 限定范围）定位，再用 `line_ranges` 精准读取；`line_ranges` 可同时取多段（如 `[[1, 5], [12, 12]]`，单行写 `[3]`）。
4. **返回片段**：把找到的相关记忆片段作为结论返回，注明来源（结构化记忆注明分区与条目内容；永久记忆注明时间）。

## 约束

- 不编造记忆内容，只返回工具读取到的真实信息。
- 永久记忆单次读取结果不能超过子代理模型的 `max_tokens`；超限时缩小 `date` 或 `from`/`to` 范围，或先用 `grep` 定位。
- 一次检索不要读取过多内容，先看索引再精准读取。
- 结构化记忆是只读条目视图，不能用文件写入动作修改；检索时忽略 `[已弃用]` 条目，除非主人问的是旧信息。
- 结构化视图的行号只用于分页读取，不代表条目身份；读取视图暂不展示条目 id。

## 输出

`output` 先写查到的内容（只摘与问题直接相关的片段，注明来源；不要粘贴整份文档），需要时再补一句反馈或结论。没有查到内容时也要明确说明。
