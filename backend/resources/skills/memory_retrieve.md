# 记忆检索

> 主人询问与过去记忆相关的问题时，使用本技能。通过资源索引探索结构化记忆与永久记忆，找到相关片段并返回给主 agent。

## 执行流程

1. **查看索引**：调用 `index` 不传参数查看资源总览；`resource` 取 `structured` 看结构化记忆的行数与标题，取 `permanent` 看当前人设可用的日期列表。
2. **按需读取**：
   - 结构化记忆：`read`（`resource` 取 `structured`）。
   - 永久记忆：`read`（`resource` 取 `permanent`），用 `date` 读取某一天，或用 `from`/`to`（ISO 8601）读取一段范围；只返回当前人设的记录。
3. **先搜再读**：内容多时先用 `grep`（`resource` 取 `structured` 或 `permanent`，永久记忆同样用 `date`/`from`/`to` 限定范围）定位，再用 `lines` 精准读取；`lines` 可同时取多段（如 `[[1, 5], [12, 12]]`，单行写 `[3]`）。
4. **返回片段**：把找到的相关记忆片段作为结论返回，注明来源（结构化记忆注明行号；永久记忆注明时间）。

## 约束

- 不编造记忆内容，只返回工具读取到的真实信息。
- 永久记忆单次读取结果不能超过子代理模型的 `max_tokens`；超限时缩小 `date` 或 `from`/`to` 范围，或先用 `grep` 定位。
- 一次检索不要读取过多内容，先看索引再精准读取。
- 结构化记忆是自由文本文件，结构由写入时自行设计，可能没有标题；行号从 1 开始。

## 输出

`output` 先写查到的内容（只摘与问题直接相关的片段，注明来源；不要粘贴整份文档），需要时再补一句反馈或结论。没有查到内容时也要明确说明。
