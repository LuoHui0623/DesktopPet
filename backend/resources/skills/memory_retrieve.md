# 记忆检索

> 主人询问与过去记忆相关的问题时，使用本技能。通过索引探索记忆库，找到相关片段并返回给主 agent。

## 执行流程

1. **查看索引**：调用 `index`（资源类型 `memory`）获取记忆库概览：结构化记忆条目列表 + 每日对话按月份列出的日期。
2. **按需读取**：根据索引判断最可能相关的条目，调用 `read`（资源类型 `memory`）读取详情。结构化记忆按 id 读取；每日对话按日期（YYYY-MM-DD）读取，可用行号区间截取。
3. **返回片段**：把找到的相关记忆片段作为结论返回，注明来源（类型 + id 或日期）。

## 约束

- 不编造记忆内容，只返回工具读取到的真实信息。
- 一次检索不要读取过多条目，先读索引再精准读取。
- 每日对话按行号区间截取时注意行号从 1 开始。
